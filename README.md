# SafeTails

SafeTails is a fullstack animal rescue platform created to help animals from war zones find safety, shelter, and care.

## Live Demo

https://safe-tails.vercel.app/

## About The Project

SafeTails is a web platform designed for animal rescue and support.  
The project provides a convenient interface for browsing rescued animals, learning their stories, and helping shelters connect with people willing to adopt or support animals in need.

The platform was created as a socially meaningful project focused on usability, accessibility, and responsive design.

## Installation & Setup

Clone the repository:

```bash
git clone https://github.com/zalishchukolia/SafeTails.git
```

Go to the project directory:

```bash
cd SafeTails
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```
